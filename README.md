# maliki — خدمة استعلام الفقه المالكي

89 كتاباً من كتب الفقه المالكي مقطعة عند حدود فهارسها الأصلية — استعلام بثلاثة طلبات، بلا تحميل ولا مفاتيح:

```
١) كل الكتب المتوفرة:        GET  /api/index.json
٢) فهرس الكتاب المختار:      GET  /api/books/<id>/toc.json
٣) محتوى العنوان المختار:    GET  /api/books/<id>/parts/<NNNN>.json.gz
```

مثال — فهرس «مختصر خليل» (id=4226):
```
curl -s https://medmrf-10.github.io/maliki/api/books/4226/toc.json
# ← {id, title:"مختصر خليل", author:"خليل بن إسحاق الجندي", toc:[{i,t,d,pg}…]}
# i = رقم الجزء، t = العنوان، d = العمق في الشجرة، pg = رقم الصفحة في المصدر
```

ثم نص أي عنوان (مثلاً جزء 5 «فصل في حكم إزالة النجاسة»):
```
curl -s https://medmrf-10.github.io/maliki/api/books/4226/parts/0005.json.gz | gunzip
# ← {i,t,pg,b,text}
```

حقل `b` = دقة حدود الجزء: `m` علامة فهرس داخلية في المصدر (92%)، `t` حدّد بمطابقة نص العنوان في صفحته، `a` تقريبي عند بداية صفحة (يُحسب من صفحة العنوان — العنوان نفسه قد يقع أعمق قليلاً داخل الصفحة).

المصدر: shamelaPure (shamela.ws) — التقسيم عند فهارس المؤلفين أنفسهم، لا تقسيم آلية.
